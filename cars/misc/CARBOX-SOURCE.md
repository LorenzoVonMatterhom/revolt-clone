# Original car-box artwork

The BMP files in this directory are copied unchanged from the RVGL common asset pack:

https://distribute.re-volt.io/packs/rvgl_assets.zip (23.1030a1)

Pages 1–3 contain the 27 normal stock cars. Panga uses column 2, row 1 of page 5.
The showroom samples those original tiles directly; it does not repaint or generate car pictures.
